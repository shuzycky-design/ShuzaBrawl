# ShuzaBrawl — сервер

Сервер приватной игры ShuzaBrawl (клиент версии 53.007). Написан на C# (.NET 8), данные хранит в MySQL.

В одном процессе работают:

- игровой сервер (вход, лобби, магазин, клубы, друзья, матчмейкинг);
- сервер боёв с ботами;
- Telegram-бот (привязка аккаунтов, VIP-маркет за звёзды Telegram);
- веб-страница с топами игроков;
- админ-панель.

> Проект неофициальный и не связан с Supercell. Игровые таблицы в `IndusBrawl.Laser.Logic/Assets` взяты из клиента игры и принадлежат её правообладателю.

## Состав репозитория

| Папка | Что внутри |
|---|---|
| `IndusBrawl.Laser.Server` | Точка входа: сеть, база данных, обработка сообщений, Telegram-бот, веб и админ-панель |
| `IndusBrawl.Laser.Logic` | Игровая логика: дом игрока, команды, бои, сообщения протокола, игровые таблицы |
| `IndusBrawl.Laser.Titan` | Низкоуровневые вещи: потоки данных, шифрование, математика |
| `schema.sql` | Структура базы данных |
| `start.sh` | Сборка, запуск и перезапуск |

Названия проектов (`IndusBrawl.Laser.*`) остались от исходной кодовой базы.

## Что нужно для запуска

- Linux;
- .NET SDK 8.0;
- MySQL 8 (или совместимая), доступная на `127.0.0.1:3306`;
- `screen` — для запуска в фоне.

## Установка

1. **База данных.** Создайте базу и таблицы:

   ```bash
   mysql -uroot -p < schema.sql
   ```

2. **Настройки.** Скопируйте пример и заполните:

   ```bash
   cp IndusBrawl.Laser.Server/config.example.json IndusBrawl.Laser.Server/config.json
   ```

   | Поле | Значение |
   |---|---|
   | `udp_host` | Внешний IP сервера — клиент подключается к нему для боёв |
   | `udp_port` | UDP-порт боёв (по умолчанию 1337) |
   | `database_username`, `database_password`, `database_name` | Доступ к MySQL |
   | `admin_port`, `admin_login`, `admin_password` | Админ-панель. Без логина и пароля она не запускается |
   | `telegram_bot_token` | Токен бота от @BotFather. Пусто — бот выключен |
   | `telegram_admin_ids` | Telegram ID администраторов бота, например `[123456789]` |
   | `tcp_port`, `web_port` | Необязательные: игровой порт (9339) и порт страницы топов (8085) |

   `config.json` в репозиторий не попадает — в нём пароли и токен.

3. **Сборка и запуск.**

   ```bash
   ./start.sh build      # собрать в run_stage
   ./start.sh restart    # применить сборку и запустить в screen-сессии "ShuzaBrawl"
   ```

   При первом запуске скопируйте `config.json` в папку `run/` — `restart` его туда не переносит, чтобы не затирать настройки работающего сервера.

`start.sh` рассчитан на установку, где .NET лежит в `~/.dotnet`, а MySQL работает в Docker-контейнере `shuzabrawl-mysql`. Если у вас иначе, поправьте начало скрипта и функцию `start_db`.

## Порты

| Порт | Назначение |
|---|---|
| TCP 9339 | Игра (вход, лобби) |
| UDP 1337 | Бои |
| TCP 8085 | Страница топов |
| TCP 8086 | Админ-панель, слушает только `127.0.0.1` |

Админ-панель наружу публикуется через обратный прокси с HTTPS (например, nginx): сессионная cookie выдаётся только по защищённому соединению.

## Управление сервером

| Команда | Действие |
|---|---|
| `./start.sh` | Запуск в текущем терминале |
| `./start.sh screen` | Запуск в фоне |
| `./start.sh build` | Сборка новой версии в `run_stage`, работающий сервер не затрагивается |
| `./start.sh restart` | Остановка, применение сборки, запуск. Игроков отключает на несколько секунд |
| `screen -r ShuzaBrawl` | Консоль сервера (выйти, не останавливая: Ctrl+A, затем D) |

Лог пишется в `logs/server.log`.

### Консольные команды

Вводятся в консоли сервера, начинаются с `/`. Основные:

| Команда | Действие |
|---|---|
| `/maxaccount #ТЭГ` | Все бойцы 11 уровня с пассивками, гаджетами, гиперзарядами и снаряжением, все скины, аватарки, пины и титулы |
| `/vip #ТЭГ` | VIP на 30 дней |
| `/changevalue #ТЭГ Поле Значение` | Числовое поле аватара: `Diamonds`, `Gold`, `PowerPoints` и другие |
| `/changehomevalue #ТЭГ Поле Значение` | Поле «дома» игрока, например `BrawlPassTokens` |
| `/ban #ТЭГ`, `/unban #ТЭГ` | Блокировка и разблокировка |
| `/maintenance` | Режим техработ |

Полный список — в `IndusBrawl.Laser.Server/Handler/CmdHandler.cs`.

## Админ-панель

- **Сводка** — онлайн, число аккаунтов, покупки VIP, режим техработ.
- **Игроки** — поиск по тэгу или имени; выдача гемов, монет, очков силы и блингов; VIP; «выдать всё»; бан; отключение; переименование; выдача стардропа.
- **Акции магазина** — акции и наборы из нескольких товаров с ценой, периодом и фоном.
- **Рассылка** — письма на внутриигровую почту одному игроку или всем, с наградами.
- **Покупки VIP** — оплаты звёздами Telegram.

## VIP

Покупается в Telegram-боте за звёзды: 30 дней — 100, 90 дней — 250, 180 дней — 400. Даёт удвоение полученных кубков и 100 гемов раз в неделю. Тарифы задаются в `IndusBrawl.Laser.Server/Telegram/VipMarket.cs`.

## Настройки, которые меняются без перезапуска

Файлы лежат в папке запуска (`run/`) и перечитываются на лету.

| Файл | Что настраивает |
|---|---|
| `starrdrop_loot.json` | Шансы редкостей стардропа и состав наград для каждой редкости |
| `starrdrop_lab.json` | Схема открытия стардропов: `PendingC` — число тапов в анимации |
| `gameplay.json` | Слоты событий и режимы |
| `battlelog_off` | Пока файл существует, история боёв отправляется пустой. Номера аккаунтов внутри файла — исключения |
| `postgame_on` | Реакции на экране результатов боя. Пустой файл — для всех боёв, с номерами аккаунтов — только для боёв с ними |
| `bots_as_players` | Боты в сообщении о конце боя описываются как обычные игроки |

## Известные ограничения

- Стардропы с пути славы и из пропуска открываются без анимации: клиент не открывает окно стардропа на этих экранах. Из магазина и при выдаче через админ-панель анимация есть.
- История боёв выключена (`battlelog_off`): клиент вылетает при её открытии, причина не найдена.
- Кнопка «палец вверх» после боя не работает.
- История боёв и очередь стардропов хранятся в памяти и не переживают перезапуск.
- `Accounts.Load(id)` для несуществующего аккаунта создаёт новый — перед вызовом проверяйте, что аккаунт есть.
